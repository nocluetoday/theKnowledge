Speed

Both run the same staged extraction. Synthesis only writes just the clinical synthesis; Full also writes the per-claim JSON records, fact set, conflicts, verification queue, and copying-risk audit. Those extra sections are most of the generated text, so Full takes considerably longer.

How much the model thinks before answering. On OpenRouter this is a share of the output token budget, so lower settings cut the wait directly.

Routes to whichever host is currently serving your chosen model fastest. Ignored by Anthropic and OpenAI, which each have one endpoint.

Saving

Opens your computer's normal Save dialog for every note, so you can put it in any folder — an Obsidian vault, a network drive, anywhere. Firefox reopens the dialog at the last folder you used. Leave this off to save straight to Downloads with no dialog.

Used when the dialog is switched off, and to pre-fill the filename when it is on. Notes go to Downloads/<subfolder>/ — Firefox does not let extensions write outside Downloads on their own, which is why saving elsewhere needs the dialog.
